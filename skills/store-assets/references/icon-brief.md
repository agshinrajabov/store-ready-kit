# Icon brief

Last checked: **2026-10-04** · numbers: 2.3.7 (no copying other apps' icons), 4.1 (copycats) · spec: the App
Store icon is 1024×1024, opaque (no alpha)

The icon appears next to the name in every search result, so it is the first impression. In one documented 4.3
case a clearly different icon was the change that got the app approved.

## Write the brief before anyone draws

| Field | Answer |
|---|---|
| The one idea | The single object, gesture or symbol that is this app's own. Often it is the differentiator or the name. |
| The niche pattern | What the top 10 icons share (one glossy 3D object on blue, a white glyph on a gradient, a mascot face). |
| How we differ | Which of those we keep for legibility, and which we refuse. Converge on readability, diverge on idea and style. |
| Silhouette test | Recognisable as a black shape at 60 px? |
| Size test | Readable at 40 px (search results on small phones)? |
| Text | None, or one letter that is the brand. Words are unreadable at icon size. |
| Colour | One dominant colour that is not the niche default. Check it against the competitors' grid. |
| Variants | Light, dark and tinted (iOS 18+). The idea must survive all three. |

## Review

Put the candidate in a row with the top 10 competitor icons at 60 px and ask someone who has not seen it to pick
the odd one out. If they cannot, the icon is not different enough.

Never use another app's icon style, mascot or composition (2.3.7, 4.1). Never use Apple hardware or system icons
as the main motif (5.2.5).

If `no-slop-design` is installed, give it this brief for the visual pass.
